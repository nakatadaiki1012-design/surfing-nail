# 出前サーファー

波に乗って、海の上のお客さんに料理を届ける 3D アクションゲームです。
`index.html` をブラウザで開くだけで遊べます（インターネット接続が必要です）。

## はじめての人へ
初めて遊ぶときだけ、「左右に動く → ジャンプ → 料理を支える」の順に、遊びながら操作を教える練習が入ります。練習中は時間が減らず、障害物も出ません。

## 3つの海
遊ぶたびに、昼 → 夕焼け → 嵐 の順で海が変わります。

| 海 | 見た目 | 遊びへの影響 |
| --- | --- | --- |
| 晴れの海 | 青空と太陽 | ふつう |
| 夕焼けの海 | オレンジと紫の空、低い太陽 | 波がおだやかで、料理がゆれにくい |
| 嵐の海 | 暗い空、雨、雷 | 料理がゆれやすい。得点は1.3倍 |

## ルール
1. オレンジの光のお店を通って、料理（ラーメン・おすし・ピザ）を受け取る
2. 緑の光のお客さんのボートまで届ける
3. 積んだ料理が倒れないように、倒れそうな方へ右手を動かして支え続ける

- 配達ごとに★1〜3の評価。1つも落とさず、はやく届けると★3（得点1.2倍）。届けるたびに +6秒
- 料理を全部落としたら、お店に取りに戻る
- コインを拾うと +10
- 岩・ブイ・サメは少なめで、1つずつ間をあけて出てくる（後半だけ2つ並びや岩の列が出る）。ぶつかると −3秒
- 左の大波のカベは ← で登れる。てっぺんまで行くとエアリアル（料理を持っているとこぼれる）
- 前から大波（はじめは1本、後半はときどき2本続けて）が来る。波ごとに選ぶ：
  - しゃがんで吸収：飛ばずに越えて加速（パンピング）。料理は安全
  - てっぺんでジャンプを合わせる：1回転の大ジャンプで高得点。着地で料理が大きくゆれる
  - 何もしない：波に飛ばされる。得点は少なく、着地でゆれる
- 制限時間は90秒

## コンボ倍率
うまいサーフィンをすると倍率（最大×5）が上がり、届けたときの得点にかかる。倍率は少しずつ下がり続け、届けると約半分を使う。

| やること | 倍率 |
| --- | --- |
| 障害物をスレスレでよける | +0.2 |
| 障害物をジャンプでとびこえる | +0.25 |
| コインを1列ぜんぶ取る | +0.3 |
| 左の波のカベに乗る（スピードも上がる） | 乗っている間ずっと上がる |
| エアリアル | +0.6 |
| 大波を乗り越える／ジャスト大ジャンプ | +0.5／+1.0 |
| 料理を安定して運び続ける（ナイスバランス） | +0.15 |
| こぼれる寸前から立て直す（ナイスリカバリー） | +0.3 |
| 鋭く切り返す（カットバック） | +0.2 |
| 大波をしゃがんで吸収（パンピング） | +0.3 |
| 届ける | +0.2（★3なら +0.5） |

- しばらく何もしないと倍率は下がっていく（倍率の下のバーが残り時間）
- こぼすと −0.5、ぶつかると ×1 に戻る

## 注文の流れ
- 1回目はピザ（こぼれにくい）、2回目はおすし、3回目はラーメン。そのあとはランダム
- 5回目からは「大盛り」が出る。こぼれやすいが得点1.5倍

## 視点
遊んでいる間はサーファーの目線（一人称）。前に海、右下に自分の右手が持ったトレーと積んだ料理が見える。

## 操作のしかた（スタート画面で選ぶ。はじめは「両手」）
| | 片手 | 両手 |
| --- | --- | --- |
| 考え方 | なめらかに乗れば料理は倒れない | 左手でサーフィン、右手で料理を支える |
| 料理 | 自然に起き上がる。急に動く・乱暴な着地・波でゆれる | 自然に起き上がる。動き出し・斜面・衝撃で傾くのを右手で立て直す |
| 立て直し | なめらかに乗る、しゃがむ（トレーは腕が自動で水平に） | 傾いた反対へトレーを傾ける |
| スマホ | 指1本で移動。2本目の指でジャンプ | 左半分で移動・ジャンプ、右半分で支える |

両手モードでは、曲がっている間は体が料理を支えてくれる（右手はまっすぐ走っているときの揺れや着地を受け止める）。

## バランスを楽しむしかけ
- **お店から料理が飛んでくる**：受け取ると、残りの皿が左右から1枚ずつ投げられて積み上がる。「←左から来るぞ！」の合図のあと着地して塔が押される。安定させておくか、飛んでくる側に少し傾けておくと「ナイスキャッチ」
- **安定ボーナス**：塔を緑の範囲に保っている間、チップが増え続ける。トレーのフチが緑に光り、1秒ごとにキラキラと音が鳴る
- **料理ごとのくせ**：
  - ラーメン：手を急に動かすとスープがはねて、チップが減る。なめらかな手さばきが大事
  - おすし：軽いので、波や風にあおられやすい
  - ピザ：重いので、ゆっくり傾くが、動き出すと止まりにくい

## バランス（両手モードの右手）
右手でトレーを左右に傾ける（右の指を右へ＝トレーの右側が下がる）。積んだ料理は、本物の皿の塔のように動く。

- **自分で立っている**：何も押さなければ、ゆらゆらしながらまっすぐに戻る。傾きが「倒れる角度」を超えると、重さで倒れていき、上の1皿が落ちる
- **押すのは本物の物理**：
  - 慣性：横に動き出すと、料理は取り残されて反対へ傾く（電車が動き出すときと同じ）
  - 波の斜面：斜面を横切るとボードとトレーが傾く
  - 衝撃：着地・波のてっぺん・飛んでくる皿・スレスレ・衝突・ときどきの風
- **立て直し方**：料理が右に傾いたらトレーを左へ。動き出す前、斜面に入る前に、先にトレーを傾けておくと上手
- 高く積むほど、ゆっくり大きく揺れ、倒れる角度も小さくなる
- しゃがむと揺れが小さくなる
- 傾けすぎると、トレー自体で料理を倒してしまう

## お皿がすべる
積んだお皿は、本物と同じように上の皿がすべる。

- **すべり出す**：塔が大きく傾くと（または強い衝撃で）、上の皿が「カチャッ」と低い方へずれ始め、止まると「コトッ」と鳴る
- **ずれは残る**：止まってもずれたまま。塔がゆがんで見え、ゆがんだ側へ倒れやすくなる
- **戻し方**：反対側へゆっくり傾けると、ずれた皿がすべって戻る。ゲージに「右にずれてる ← そっと左へ」と出る
- **はみ出し注意**：下の皿のフチを越えると「お皿がはみ出してる！」と鳴ってグラグラする。少しのあいだに反対へ傾ければ助かる。間に合わないと、その皿から上が全部落ちる
- **ぴったりボーナス**：ゆがんだ塔をまっすぐに戻すと「ぴったり！」でチップ
- 料理でちがう：ラーメンのどんぶりはすべりやすい、おすしの皿はすべりにくい、ピザの箱はすべりやすいけどフチまで遠い
- 片手モードでは、腕が自動でずれも少しずつ直してくれる

## 操作
| | スマホ | パソコン |
| --- | --- | --- |
| 移動（左手） | 画面の左半分のどこでも、左右にずらす | A D（← →） |
| ジャンプ（左手） | 上にずらす、またはポンとタップ | W（↑・スペース） |
| しゃがむ（左手） | 下にずらす | S（↓） |
| トレーを傾ける（右手） | 画面の右半分のどこでも、左右にずらす | マウスを左右に動かす |

- 触った場所がスティックの中心になるので、小さなボタンを狙わなくていい
- 着地の直前にジャンプを押しても、着地してすぐ飛ぶ

## 空中の技（着地で料理がゆれる）
画面が回転すると見づらいので、スピンなど体が回る技はありません。
| 技 | やり方 | 得点 | 着地のゆれ |
| --- | --- | --- | --- |
| グラブ | 空中で下を入れ続ける | 120 | 小さめ |

- 料理を持ったまま決めると得点アップ（ラーメンがいちばん高い）
- スレスレでよけたときも、料理が少しゆれる

## サーフィンの動き
- 曲がりには慣性がある。エッジが入るまで一瞬かかり、すべるように抜ける。体も曲がる方へ倒れる
- 強く曲がるとスピードが落ちる
- 波の下り斜面に着地するとなめらか（クリーン着地）。平らな所や上りに落ちると衝撃が大きい
- ぶつかると転んで（ワイプアウト）、少しの間あやつれない
- しゃがむと波を吸収でき、料理も安定する。ただし曲がりにくく、平らな所では少し遅くなる
- 波の斜面を登ると減速、下ると加速。下りでしゃがむとさらに加速（パンピング）
- 上り坂でジャンプすると、ジャンプ台のように高く飛ぶ

## 得点とランク
得点の中心は配達（全体の約7割）。技は上乗せ。

| ランク | 得点 |
| --- | --- |
| S | 40,000点以上 |
| A | 28,000点以上 |
| B | 17,000点以上 |
| C | それ未満 |

目安は、自動プレイで90秒を通しで何度も遊ばせた結果から決めた（上手い操作で約42,000点、ふつうで約34,000点、初心者相当で約22,000点）。

## そのほか
- 左上の「II」で一時停止（パソコンは Esc か P）。別のタブに切り替えたときも自動で止まる
- 左上の「音」で音のオン・オフ
