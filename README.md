# サーフ出前

波に乗って、海の上のお客さんに料理を届ける 3D アクションゲームです。
`index.html` をブラウザで開くだけで遊べます（インターネット接続が必要です）。

## ルール
1. オレンジの光のお店を通って、料理（ラーメン・おすし・ピザ）を受け取る
2. 緑の光のお客さんのボートまで届ける
3. 運ぶ間は右手でトレーを傾けてバランスを取る。バランスがくずれると料理がこぼれる

- 配達ごとに★1〜3の評価。85%以上のこして、はやく届けると★3（得点1.2倍）。届けるたびに +6秒
- 料理が全部こぼれたら、お店に取りに戻る
- コインを拾うと +10
- 岩・ブイ・サメにぶつかると −3秒
- 左の大波のカベは ← で登れる。てっぺんまで行くとエアリアル（料理を持っているとこぼれる）
- 前から大波のセット（1〜3本、だんだん高くなる）が何度も来る。波ごとに選ぶ：
  - しゃがんで吸収：飛ばずに越えて加速（パンピング）。料理は安全
  - てっぺんでジャンプを合わせる：1回転の大ジャンプで高得点。着地で料理が大きくゆれる
  - 何もしない：波に飛ばされる。得点は少なく、着地でゆれる
- 大波が近くにある間はスコア2倍
- 制限時間は90秒

## コンボ倍率
うまいサーフィンをすると倍率（最大×5）が上がり、届けたときの得点にかかる。

| やること | 倍率 |
| --- | --- |
| 障害物をスレスレでよける | +0.2 |
| 障害物をジャンプでとびこえる | +0.25 |
| コインを1列ぜんぶ取る | +0.3 |
| 左の波のカベに乗る（スピードも上がる） | 乗っている間ずっと上がる |
| エアリアル | +0.6 |
| 大波を乗り越える／ジャスト大ジャンプ | +0.5／+1.0 |
| 料理を安定して運び続ける（ナイスバランス） | +0.15 |
| こぼれる寸前から立て直す（ナイスリカバリー） | +0.3 |
| 鋭く切り返す（カットバック） | +0.2 |
| 大波をしゃがんで吸収（パンピング） | +0.3 |
| 届ける | +0.2（★3なら +0.5） |

- しばらく何もしないと倍率は下がっていく（倍率の下のバーが残り時間）
- こぼすと −0.5、ぶつかると ×1 に戻る

## 注文の流れ
- 1回目はピザ（こぼれにくい）、2回目はおすし、3回目はラーメン。そのあとはランダム
- 5回目からは「大盛り」が出る。こぼれやすいが得点1.5倍

## バランス（右手）
- 料理を運んでいる間は、右手でトレーを左右に傾けてバランスを取る
- 曲がると料理が横にゆれるので、曲がる方向にトレーを傾ける
- 大波のカベではボードが傾くので、反対に傾けて水平にたもつ
- ジャンプの着地や衝突では大きくゆれる。右手で受け止めればこぼれない
- こぼれると、おすし・ピザ・ラーメンの具が実際にトレーから落ちて海に水しぶきを上げ、スープは流れ落ち、画面のふちにも飛び散る
- 右下の小窓に料理の3Dアップが映る。スープの面がフチに迫る／おすし・ピザが低いほうへすべる様子で、こぼれそう具合がわかる
- 小窓の下のメーターは、印が緑の範囲にあれば安全
- ラーメンがいちばんこぼれやすく、おすし、ピザの順に安定

## 操作
| | スマホ | パソコン |
| --- | --- | --- |
| 移動（左手） | 左下のスティックを左右に | A D（← →） |
| ジャンプ（左手） | スティックを上にはじく | W（↑・スペース） |
| しゃがむ（左手） | スティックを下に | S（↓） |
| トレーを傾ける（右手） | 右下のパッドを左右に | マウスを左右に動かす |

## サーフィンの動き
- しゃがむと波を吸収でき、料理も安定する。ただし曲がりにくく、平らな所では少し遅くなる
- 波の斜面を登ると減速、下ると加速。下りでしゃがむとさらに加速（パンピング）
- 上り坂でジャンプすると、ジャンプ台のように高く飛ぶ
