# ネイルサーフ

波に乗りながら、お客さんのネイルを仕上げる 3D アクションゲームです。

## あそびかた
`index.html` をブラウザで開くだけで遊べます（インターネット接続が必要です）。

| 操作 | パソコン | スマホ |
| --- | --- | --- |
| 左右に移動 | ← → | ◀ ▶ ボタン |
| ジャンプ | ↑ | ジャンプ ボタン |
| ネイルをぬる | スペース（押しっぱなし） | ぬる ボタン（押しっぱなし） |

### ルール（3つだけ）
1. 上の「ご注文」と同じ色のボトルをひろう
2. 画面をドラッグしてハケを動かし、自分でツメをぬる（パソコンはマウスでドラッグ）。ぬっている間はツメにズームする。ぬり終わったら「できた！」（Enter）、ツメ全体がぬれると自動で完成
3. ぬっている間はじっとすると、はみださずにきれいに仕上がる

- 岩・ブイ・サメはよけるかジャンプ。ぶつかると3秒へる
- 5本ぬるとお客さん完成。ボーナス＋5秒
- ときどき来るビッグウェーブの間はスコア2倍

### 大波アクション
- 左にある大波のカベは ← を押し続けると登れる（はなすとすべり落ちる）。カベにいる間は「波ライド」で得点がたまる
- てっぺんまでスピードを出して登ると「エアリアル」。くるっと1回転して着地すると +400（ビッグウェーブ中は2倍）
- 次のエアリアルは、いったんカベを少し下りてから
- ビッグウェーブ中はカベが高くなり、カベの上にもボトルが出る

### 操作（スマホ）
- 左手：左下のスティック。左右にずらすと移動、上にはじくとジャンプ
- 右手：画面をドラッグしてぬる。右下の「できた！」で仕上げ

### 手のゆれ
- 曲がる・波で上下にゆれる・ジャンプの着地などで、ツメの手とハケの手がバネのようにゆれてズレる
- ズーム中は海が見えにくい。障害物が近づくと画面のふちが赤くなる
