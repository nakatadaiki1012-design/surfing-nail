# ネイルサーフ

波に乗りながら、お客さんのネイルを仕上げる 3D アクションゲームです。

## あそびかた
`index.html` をブラウザで開くだけで遊べます（インターネット接続が必要です）。

| 操作 | パソコン | スマホ |
| --- | --- | --- |
| 左右に移動 | ← → | ◀ ▶ ボタン |
| ジャンプ | ↑ | ジャンプ ボタン |
| ネイルをぬる | スペース（押しっぱなし） | ぬる ボタン（押しっぱなし） |

### ネイルのぬり方
- 波の上のネイルボトルをひろうと、ハケにその色のポリッシュが入ります（残量も満タンに）。
- 左下の拡大画面がいまぬっているツメです。ぬるボタンを押している間、ハケが根元から先へ動きます。
- プロと同じ「真ん中 → 左 → 右」の3ストロークで仕上げます。ムラがあるとタッチアップ（最大2回）。
- ぬっている間に動いたり、大波やジャンプの着地でゆれると、ハケがずれて指にはみだします。
- ポリッシュが少ないとハケが細くなり、スジ（ムラ）になります。
- ぬったツメは2.6秒「かわかし中」。かわく前にぶつかるとヨレて減点。
- 金色のボトルはラメ。つぎのツメの得点が1.5倍。

### 得点とバランス
- 3ストロークで、ムラなし・はみだしなし → パーフェクト。コンボで得点アップ。
- 5本すべてきれいに仕上げると「大満足」ボーナス＋5秒。早く仕上げるほどチップが多い。
- 岩・ブイ・サメにぶつかると −3秒。障害物は必ず通り抜けられる配置で出てきます。
- ときどき来る「ビッグウェーブ」の間はスコア2倍（そのかわり手がゆれやすい）。
- 制限時間は90秒（ボーナスで延長あり）。
