# サーフ出前

波に乗って、海の上のお客さんに料理を届ける 3D アクションゲームです。
`index.html` をブラウザで開くだけで遊べます（インターネット接続が必要です）。

## ルール
1. オレンジの光のお店を通って、料理（ラーメン・おすし・ピザ）を受け取る
2. 緑の光のお客さんのボートまで届ける
3. 運ぶ間は右手でトレーを傾けてバランスを取る。バランスがくずれると料理がこぼれる

- はやく、こぼさず届けるほど得点とチップが増える。届けるたびに +6秒
- 85%以上のこして届けると「きれいにお届け」。続けるとボーナスアップ
- 料理が全部こぼれたら、お店に取りに戻る
- コインを拾うと +10
- 岩・ブイ・サメにぶつかると −3秒
- 左の大波のカベは ← で登れる。てっぺんまで行くとエアリアル（料理を持っているとこぼれる）
- ときどき来るビッグウェーブの間はスコア2倍
- 制限時間は90秒

## バランス（右手）
- 料理を運んでいる間は、右手でトレーを左右に傾けてバランスを取る
- 曲がると料理が横にゆれるので、曲がる方向にトレーを傾ける
- 大波のカベではボードが傾くので、反対に傾けて水平にたもつ
- ジャンプの着地や衝突では大きくゆれる。右手で受け止めればこぼれない
- 右下の小窓に料理の3Dアップが映る。スープの面がフチに迫る／おすし・ピザが低いほうへすべる様子で、こぼれそう具合がわかる
- 小窓の下のメーターは、印が緑の範囲にあれば安全
- ラーメンがいちばんこぼれやすく、おすし、ピザの順に安定

## 操作
| | スマホ | パソコン |
| --- | --- | --- |
| 移動（左手） | 左下のスティックを左右に | A D（← →） |
| ジャンプ（左手） | スティックを上にはじく | W（↑・スペース） |
| トレーを傾ける（右手） | 右下のパッドを左右に | マウスを左右に動かす |
