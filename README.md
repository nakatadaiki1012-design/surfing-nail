# 出前サーファー

波に乗って、海の上のお客さんに料理を届ける 3D アクションゲームです。
`index.html` をブラウザで開くだけで遊べます（インターネット接続が必要です）。

## はじめての人へ
初めて遊ぶときだけ、「左右に動く → ジャンプ → 料理を支える」の順に、遊びながら操作を教える練習が入ります。練習中は時間が減らず、障害物も出ません。

## 3つの海
遊ぶたびに、昼 → 夕焼け → 嵐 の順で海が変わります。

| 海 | 見た目 | 遊びへの影響 |
| --- | --- | --- |
| 晴れの海 | 青空と太陽 | ふつう |
| 夕焼けの海 | オレンジと紫の空、低い太陽 | 波がおだやかで、料理がゆれにくい |
| 嵐の海 | 暗い空、雨、雷 | 料理がゆれやすい。得点は1.3倍 |

## ルール
1. オレンジの光のお店を通って、料理（ラーメン・おすし・ピザ）を受け取る
2. 緑の光のお客さんのボートまで届ける
3. 積んだ料理が倒れないように、倒れそうな方へ右手を動かして支え続ける

- 配達ごとに★1〜3の評価。1つも落とさず、はやく届けると★3（得点1.2倍）。届けるたびに +6秒
- 料理を全部落としたら、お店に取りに戻る
- コインを拾うと +10
- 岩・ブイ・サメは少なめで、1つずつ間をあけて出てくる（後半だけ2つ並びや岩の列が出る）。ぶつかると −3秒
- 左の大波のカベは ← で登れる。てっぺんまで行くとエアリアル（料理を持っているとこぼれる）
- 前から大波のセット（1〜3本、だんだん高くなる）が何度も来る。波ごとに選ぶ：
  - しゃがんで吸収：飛ばずに越えて加速（パンピング）。料理は安全
  - てっぺんでジャンプを合わせる：1回転の大ジャンプで高得点。着地で料理が大きくゆれる
  - 何もしない：波に飛ばされる。得点は少なく、着地でゆれる
- 制限時間は90秒

## コンボ倍率
うまいサーフィンをすると倍率（最大×5）が上がり、届けたときの得点にかかる。倍率は少しずつ下がり続け、届けると約半分を使う。

| やること | 倍率 |
| --- | --- |
| 障害物をスレスレでよける | +0.2 |
| 障害物をジャンプでとびこえる | +0.25 |
| コインを1列ぜんぶ取る | +0.3 |
| 左の波のカベに乗る（スピードも上がる） | 乗っている間ずっと上がる |
| エアリアル | +0.6 |
| 大波を乗り越える／ジャスト大ジャンプ | +0.5／+1.0 |
| 料理を安定して運び続ける（ナイスバランス） | +0.15 |
| こぼれる寸前から立て直す（ナイスリカバリー） | +0.3 |
| 鋭く切り返す（カットバック） | +0.2 |
| 大波をしゃがんで吸収（パンピング） | +0.3 |
| 届ける | +0.2（★3なら +0.5） |

- しばらく何もしないと倍率は下がっていく（倍率の下のバーが残り時間）
- こぼすと −0.5、ぶつかると ×1 に戻る

## 注文の流れ
- 1回目はピザ（こぼれにくい）、2回目はおすし、3回目はラーメン。そのあとはランダム
- 5回目からは「大盛り」が出る。こぼれやすいが得点1.5倍

## 視点
遊んでいる間はサーファーの目線（一人称）。前に海、右下に自分の右手が持ったトレーと積んだ料理が見える。

## 操作のしかた（スタート画面で選ぶ。はじめは「両手」）
| | 片手 | 両手 |
| --- | --- | --- |
| 考え方 | なめらかに乗れば料理は倒れない | 左手でサーフィン、右手で料理を支える |
| 料理 | 自然に起き上がる。急に曲がる・乱暴な着地・波でゆれる | 放っておくと倒れていく。右手で支え続ける |
| 立て直し | 倒れそうな方へ曲がる、しゃがむ | 倒れそうな方へ右手を動かす |
| スマホ | 指1本で移動。2本目の指でジャンプ | 左半分で移動・ジャンプ、右半分で支える |

両手モードでは、曲がっている間は体が料理を支えてくれる（右手はまっすぐ走っているときの揺れや着地を受け止める）。

## バランス（両手モードの右手）
料理は高く積んで運ぶ。積んだ料理は「逆さの振り子」で、放っておくとどんどん倒れていく。

- 倒れそうな方へ右手を動かすと、トレーが下に入って立て直せる（ほうきを手のひらで立てる遊びと同じ）
- 動かしすぎると反対側へ倒れるので、細かく支え続ける
- 塔は落ち着いてくるほど次のぐらつきが早く来て、限界のほうへ押される。いつもぎりぎりを支える
- 限界の手前では塔がこらえ、時間が一瞬スローになり、画面のふちが赤く脈打って鼓動が鳴る
- 限界を超えると、いちばん上がずるっとすべり始め、約0.3秒こらえきれないと落ちる。残りは少し戻るので、立て直すチャンスがある
- 注文が進むほど高く積む（2人前から始まり、3回ごとに1つ増えて最大6人前）。高いほど倒れやすく、得点も高い
- 最初の数回は練習用に倒れにくくしてある
- ラーメン（フタ付きどんぶり）がいちばん倒れやすく、おすし（すし桶）、ピザ（箱）の順に安定
- 曲がる・波のカベ・大波・着地・スレスレ・衝突・数秒おきの不意の「ぐらっ」で傾く
- しゃがむと倒れにくくなる
- 右下の小窓に積んだ料理のアップが映り、下のメーターの印が傾いている向きを示す

## 操作
| | スマホ | パソコン |
| --- | --- | --- |
| 移動（左手） | 画面の左半分のどこでも、左右にずらす | A D（← →） |
| ジャンプ（左手） | 上にずらす、またはポンとタップ | W（↑・スペース） |
| しゃがむ（左手） | 下にずらす | S（↓） |
| 料理を支える（右手） | 画面の右半分のどこでも、倒れそうな方へずらす | マウスを倒れそうな方へ動かす |

- 触った場所がスティックの中心になるので、小さなボタンを狙わなくていい
- 着地の直前にジャンプを押しても、着地してすぐ飛ぶ

## 空中の技（難しいほど、着地で料理が大きくゆれる）
| 技 | やり方 | 得点 | 着地のゆれ |
| --- | --- | --- | --- |
| スピン 360 / 720 / 1080 | 空中で左右を入れ続ける | 150 / 450 / 900 | 回転数に比例して大きい |
| グラブ | 空中で下を入れ続ける | 120 | 小さめ |
| 半端な向きで着地 | — | なし | 大きい（着地が乱れた） |

- 料理を持ったまま決めると得点アップ（ラーメンがいちばん高い）
- スレスレでよけたときも、料理が少しゆれる

## サーフィンの動き
- 曲がりには慣性がある。エッジが入るまで一瞬かかり、すべるように抜ける。体も曲がる方へ倒れる
- 強く曲がるとスピードが落ちる
- 波の下り斜面に着地するとなめらか（クリーン着地）。平らな所や上りに落ちると衝撃が大きい
- ぶつかると転んで（ワイプアウト）、少しの間あやつれない
- しゃがむと波を吸収でき、料理も安定する。ただし曲がりにくく、平らな所では少し遅くなる
- 波の斜面を登ると減速、下ると加速。下りでしゃがむとさらに加速（パンピング）
- 上り坂でジャンプすると、ジャンプ台のように高く飛ぶ

## 得点とランク
得点の中心は配達（全体の約7割）。技は上乗せ。

| ランク | 得点 |
| --- | --- |
| S | 40,000点以上 |
| A | 28,000点以上 |
| B | 17,000点以上 |
| C | それ未満 |

目安は、自動プレイで90秒を通しで何度も遊ばせた結果から決めた（上手い操作で約42,000点、ふつうで約34,000点、初心者相当で約22,000点）。
