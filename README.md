# ネイルサーフ

波に乗りながら、お客さんのネイルを仕上げる 3D アクションゲームです。

## あそびかた
`index.html` をブラウザで開くだけで遊べます（インターネット接続が必要です）。

| 操作 | パソコン | スマホ |
| --- | --- | --- |
| 左右に移動 | ← → | ◀ ▶ ボタン |
| ジャンプ | ↑ | ジャンプ ボタン |
| ネイルをぬる | スペース（押しっぱなし） | ぬる ボタン（押しっぱなし） |

- 波の上のネイルボトルをひろうと、ふでがその色になります。
- 右上の「ご注文」と同じ色でツメをぬりましょう。
- ぬっている間に大きく動くと「はみだし」になります。手の安定メーターを見ながらぬりましょう。
- 岩・ブイ・サメにぶつかると、ぬりかけのツメはやり直し、時間も3秒へります。
- ときどき来る「ビッグウェーブ」の間はスコア2倍。
- 制限時間は90秒です。
