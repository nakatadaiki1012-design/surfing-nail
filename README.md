# ネイルサーフ

波に乗りながら、お客さんのネイルを仕上げる 3D アクションゲームです。

## あそびかた
`index.html` をブラウザで開くだけで遊べます（インターネット接続が必要です）。

| 操作 | パソコン | スマホ |
| --- | --- | --- |
| 左右に移動 | ← → | ◀ ▶ ボタン |
| ジャンプ | ↑ | ジャンプ ボタン |
| ネイルをぬる | スペース（押しっぱなし） | ぬる ボタン（押しっぱなし） |

### ルール（3つだけ）
1. 上の「ご注文」と同じ色のボトルをひろう
2. ぬるボタンを長押しでツメをぬる（ハケが真ん中→左→右の3回で自動でぬる）
3. ぬっている間はじっとすると、はみださずにきれいに仕上がる
